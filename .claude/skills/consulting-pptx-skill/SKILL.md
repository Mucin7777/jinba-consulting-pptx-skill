# consulting-pptx-skill（リポジトリごとセッションに入れたときの入口）

本体はリポジトリ直下の `SKILL.md`。このファイルは、Claude Code のクラウド環境などでこのリポジトリをセッションに入れたとき、スキルとして読み込まれるための入口（`~/.claude/skills/` に clone した場合は直下の `SKILL.md` が読まれ、このファイルは使われない）。

1. リポジトリ直下の `SKILL.md`（このファイルから見て `../../../SKILL.md`）を読み、その手順に従う。`references/`・`templates/`・`scripts/`・`local/` のパスはすべてリポジトリ直下から数える
2. Linux（クラウド環境・Docker）では、作業の前に一度 `bash scripts/setup_linux.sh` を実行する。和文フォント（Noto CJK）を入れ、パーツ集の書体名（Yu Gothic・Yu Mincho・ヒラギノ）をそれに対応づける。これをしないと和文が中国語の字形で描かれ、見出しの明朝もゴシックになる。何度実行してもよい
